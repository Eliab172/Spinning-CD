
# Spinning Cd #

The Spinning CD is a 3D printed case that has a disc that spins with a motor connected by switches, potentiometer, and a USB-c module. 


**Overview**

The Spining Cd is 3D printed case that has 3 separate parts that connect the first part is the disc with rings of grip holding the motor connected to a shaft that can be connected to a motor. The Second case is the holding case that holds the Cd disc that function is just to make sure the CD Spinner is not spinning out. The last base piece that is on the bottom is where all the electronics are. 

**Features**

- USB-C Module Port Female 
- Adjustable control from potentiometer
- Switch controlling on and off. 
- Dc Motor spinning 3D Disc 

**Safety**

- The DC motor spins fast to injure your hands. Keep your hand off the Dc motor when spinning 
- Do not touch the inner case you will get hurt due to the high speed of the CD  
- Do not touch the bare wire with hands 
- Do not increase potentiometer for too long will cause over heating in motor and USB-C module.
